# Agent Workflow

This document outlines the standard procedures and steps the agent should follow when executing tasks in this project.

## Standard Procedure
1. **Analyze:** Understand the user's request and check relevant documentation in the `docs/` folder.
2. **Plan:** If the task is complex, create an implementation plan and ask for user approval.
3. **Execute:** Write or modify the code according to the plan, project settings, and coding conventions.
4. **Verify:** Check that the changes meet the requirements and do not break existing functionality.
