# Map Generation & Minimap System Spec

## 1. 개요 (Overview)
본 시스템은 정해진 크기(A * B)의 **미리 제작된 방(Room Prefab)들을 전체 맵 영역(X * Y) 내에 무작위로 배치**하여 절차적(Procedural)인 오픈형 맵을 생성하고, 이를 2D 도면 형태의 **미니맵(Minimap)**으로 플레이어에게 제공하는 기능입니다. 기존 "그리드 빌딩 시스템(WorldGridManager)"과 연동되도록 설계되었습니다.

---

## 2. 맵 생성 시스템 (Map Generator)
스크립트: `MapGenerator.cs` (네임스페이스: `Coop.MapGeneration`)

### 2.1. 맵 생성 파이프라인 (랜덤 팩킹 알고리즘)
1. **면적 정렬**: 배치 성공률을 높이기 위해 배치 대기열의 방들을 면적(Width * Height) 내림차순으로 정렬합니다. 큰 방부터 배치합니다.
2. **랜덤 팩킹 (Fisher-Yates Shuffle)**: 
   - 맵 영역 내에서 해당 방이 들어갈 수 있는 모든 경우의 수(좌표 + 회전)를 리스트화한 후 무작위로 섞습니다.
   - 하나씩 꺼내며 맵 밖을 벗어나지 않고 다른 방과 겹치지 않는 빈자리를 찾으면 맵에 점유(Occupied) 처리하고 넘어갑니다.
3. **필수 방 vs 선택적 방**:
   - `requiredRooms`: 무조건 맵에 배치되어야 하는 필수 방 목록 (사무실, 발전실 등). 배치가 실패하면 전체 맵 생성을 다시 시도(Retry)합니다.
   - `optionalRoomPool`: 선택적 방 후보군. 확률적으로 `optionalRoomCount` 개수만큼 추첨되어 배치됩니다. 자리가 부족해 배치에 실패하더라도 에러 없이 해당 방은 건너뜁니다.
4. **그리드 스냅 (Instantiate)**: `WorldGridManager`의 `CellSize`와 정중앙(Center) 피벗 기준에 맞게 방 프리팹을 인스턴스화(Instantiate) 합니다.
5. **빌딩 시스템 연동**: 맵 생성기는 단순히 방의 바운딩 박스를 겹치지 않게 맵에 뿌려주는 역할만 합니다. 맵 배치가 완료되면, **방 프리팹 내부에 세팅된 `NoBuildArea` 및 벽 오브젝트들이 알아서 `WorldGridManager`에 그리드 점유 상태를 등록**하여 빌딩 가능 여부를 결정합니다.

## 3. 방 데이터 구조 (Room Prefab Data)
스크립트: `RoomPrefabData.cs` (ScriptableObject)
- **prefab**: 실제 게임 월드에 스폰될 방 프리팹 (Pivot은 정중앙 기준)
- **size**: 그리드 기준 방의 가로, 세로 크기 (예: 5 x 10)
- **allowRotation**: 배치 시 회전(0, 90, 180, 270도) 허용 여부
- **mapRoomName**: 미니맵에 표시될 텍스트 (방 이름)
- **mapColor**: 미니맵에서 이 방을 표시할 2D 블록 배경 색상

## 4. 미니맵 시스템 (Minimap UI)
스크립트: `MinimapUIManager.cs` (네임스페이스: `Coop.UI`)

### 4.1. UI 도면 (추상화 렌더링)
- 렌더 텍스처(카메라 렌더링) 방식이 아닌, `MapGenerator`가 제공하는 데이터(크기, 좌표, 색상)를 이용해 2D UI 캔버스 패널 위에 **색상 블록(Image)**과 **텍스트(TextMeshPro)**로 지도를 그리는 방식입니다.
- 전장의 안개(Fog of War) 없이 게임 시작부터 전체 맵 레이아웃을 모두 확인할 수 있습니다.
- 플레이어가 건설한 구체적인 구조물(벽, 가구 등)은 표시되지 않으며, 방들의 큰 레이아웃 도면만 제공합니다.

### 4.2. 주요 기능 및 조작
- **토글**: `New Input System`을 사용하여 **M키**를 누르면 미니맵 전체 창이 열리거나 닫힙니다.
- **마우스 드래그 (Pan)**: 미니맵 창이 열린 상태에서 마우스 좌클릭 또는 휠 클릭으로 지도를 이리저리 끌어서 이동할 수 있습니다.
- **줌 (Zoom)**: 마우스 휠 스크롤을 이용해 지도를 줌인 / 줌아웃 할 수 있습니다.
- **실시간 플레이어 위치 추적**: `Player` 태그가 부착된 본인 및 아군 오브젝트들의 월드 좌표를 미니맵 픽셀 좌표로 실시간 변환하여 지도 위에 아이콘(초록색 마커)으로 표시합니다.
